# PalmClix 1.1.0

**New: Windows version.** The same camera-shaped interface for Windows 10/11. Right-click the camera for File, Edit, View, Go, Camera and Window menus. It needs a one-time WinUSB driver install with Zadig (see README).

**macOS:** the Import Studio window is gone and its options moved to the menu bar. The window frame is gone too, so only the camera shape shows, and you drag it by its body. The Preview button now opens the selected photos in Preview.

Downloads:
- `PalmClix-macOS.zip`: Apple Silicon, macOS 12+. Ad-hoc signed; right-click → Open the first time.
- `PalmClix-Windows.zip`: 64-bit Windows 10/11. Unsigned; SmartScreen → More info → Run anyway.
